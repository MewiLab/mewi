# Contributing to Mewi

Thanks for your interest in Mewi.

## Repository Scope

This repository is a proof of concept. It demonstrates the idea behind Mewi and shares selected pieces of code, but it is not a complete runnable game.

Some Unity assets were purchased and cannot be redistributed, so they are intentionally excluded from the repository.

## Where Contributions Can Go

### Seeing from Other Sides

Explore how autonomous cats with conflicting perspectives could help people practice understanding others in a low-stakes world.

### From Virtual Strays to Real Ones

Explore agents based on real shelter cats, connected to livestreams, adoption information, or donations so virtual attention can help real animals.

### Strangers Connected Through an Agent

Explore a cat that moves between players and carries traces of each relationship. Can people who never meet still become connected through an agent they each cared for?

### Other Questions

New questions are welcome, especially around embodied agents, autonomous exploration, memory, emergent behavior, human-AI coordination, relationships, and care.

## How to Contribute

1. Open an issue describing the question or idea you want to explore.
2. Keep pull requests small and explain what changed and why.
3. Include a simple test, demo, or evidence when relevant.
4. Do not commit purchased assets, secrets, or personal data.

For architecture work, treat the newest ADRs and the current code as the source of truth because older documents may be outdated.
